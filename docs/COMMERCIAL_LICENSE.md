- **Who sponsors.** Preferably the organization's own GitHub account, so the license is clearly the organization's. An
  individual may sponsor on the organization's behalf; in that case, keep the GitHub Sponsors receipt as the record of

- **Price.** The amount shown on the tier on the [Sponsors page](https://github.com/sponsors/agadek).

## How to get it

1. Open <https://github.com/sponsors/agadek>, preferably signed in as the organization.
2. Pick the **Commercial license** tier and complete the sponsorship. GitHub sends a receipt for each payment, and

3. That is all: keep using the plugin from JetBrains Marketplace.

If your organization cannot pay through GitHub Sponsors, open an issue or contact the author through the
[GitHub profile](https://github.com/agadek) to arrange another way.
