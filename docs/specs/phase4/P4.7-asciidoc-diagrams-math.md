# P4.7 Diagrams and math in AsciiDoc

Plan: [PHASE4.md](../../PHASE4.md). Decision: [ADR 0006](../../adr/0006-asciidoc-rendering-reuse.md). Requirement:
FR-22. Depends on P4.4.

## Goal

Draw Mermaid diagrams and formulas in AsciiDoc diffs with the bundled Mermaid and KaTeX, compared and shown the same
way as in Markdown (fixtures 27, 28 and 40).

## Scope

### Mermaid

- A listing or literal block with style `mermaid` (`[mermaid]` + `----` or `....`) becomes a `MERMAID` block when
  `options.renderMermaid` is on, with `lines` holding its `CODE_FENCE` and `CODE_LINE` blocks for the source diff, as
  for a ` ```mermaid ` fence. Its line range covers both delimiters and the style line.
- It renders as `div.mdr-block.mdr-mermaid > pre.mdr-mermaid-code`, with `mdr-mermaid-row` and the
  `details.mdr-mermaid-source` toggle when modified. The page script draws it unchanged.
- Block attributes Mermaid itself does not read (`format`, `width`, `target` from asciidoctor-diagram) are ignored;
  a change in them is a change in the block's key and shows the "Show source changes" toggle.
- Other asciidoctor-diagram styles (`plantuml`, `graphviz`, `ditaa`, ...) stay code blocks.

### Math

- A document whose `stem` attribute is `latexmath`, or unset/`asciimath` but with explicit `latexmath:[...]` macros:
  - inline `latexmath:[...]`, and `stem:[...]` when `stem` is `latexmath`, become `span.mdr-math.mdr-math-inline` with
    the TeX source, and are atoms of `plainText`, so the word diff keeps each formula whole;
  - `[latexmath]` blocks, and `[stem]` blocks when `stem` is `latexmath`, delimited by `++++`, become `MATH` blocks
    with their lines for the source diff.
- AsciiMath (`asciimath:[...]`, `stem` set to `asciimath`, the Asciidoctor default when `:stem:` is set without a
  value) is not drawn: it stays monospace source, compared as text, and the formula element gets `mdr-math-failed`
  with the note "AsciiMath is not supported".
- Asciidoctor converts stem macros to `\(...\)` / `\[...\]` for MathJax; the front end reads the source from the
  node instead of the converted HTML, so the conversion is not parsed back.
- With `Render math` off, formulas stay monospace source, as for Markdown.

## Out of scope

AsciiMath rendering, asciidoctor-diagram styles other than Mermaid, Kroki.

## Tests

- Fixture `66-adoc-math`: inline and block `latexmath`, `stem` with `:stem: latexmath`, an AsciiMath formula (not

- `HtmlPageTest`: the Mermaid and KaTeX scripts are inlined for AsciiDoc pages with diagrams or formulas, and not
