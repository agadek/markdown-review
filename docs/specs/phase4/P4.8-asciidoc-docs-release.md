# P4.8 Fixtures, documentation and release

Plan: [PHASE4.md](../../PHASE4.md). Requirements: all of phase 4. Depends on P4.4 to P4.7 and P4.9, which
ships in the same release (1.4.0).

## Goal

Ship AsciiDoc support with documentation that says exactly what is supported, and close phase 4's paperwork.

## Scope

### Specification and contract

- [SPECIFICATION.md](../../SPECIFICATION.md): FR-16 to FR-24 and NFR-11 to NFR-15 into the requirement tables; a
  "Supported AsciiDoc" section next to "Supported Markdown"; AsciiDoc removed from "Out of scope" (reStructuredText
  stays); the platform section names the AsciiDoc plugin as optional; the purpose says "Markdown and AsciiDoc".
- [ENGINE_CONTRACT.md](../../ENGINE_CONTRACT.md): `RenderRequest.format`, the AsciiDoc block kinds and their table,
  containers, the `AsciidoctorProvider` extension point, and the rule that no class outside the AsciiDoc packages
  imports `org.asciidoctor`.
- `src/main/resources/pl/mdreview/css/CLASSES.md`: final list of AsciiDoc classes (from P4.4).
- ADR 0002 to 0007: status "accepted", with what changed during implementation.

### Fixtures

- `src/test/resources/fixtures/README.md`: the `.adoc` naming rule and the AsciiDoc rows of the case table.
- `src/test/resources/fixtures/.gitattributes` already keeps every file byte for byte (`* -text`), `.adoc` included;
  check that it still does.

### User-facing docs

- README: "Markdown and AsciiDoc" in the description, a short AsciiDoc section (what needs the AsciiDoc plugin, what is
  not supported: includes, extensions other than Mermaid, AsciiMath, mixed-format pairs), a screenshot.
- `plugin.xml` description: an AsciiDoc bullet and the AsciiDoc plugin requirement.
- `site/index.html`: the same section and screenshot.
- Screenshots: `docs/screenshots/sample-old.adoc` / `sample-new.adoc`, side by side light and merged dark, made like
  the Markdown ones.
- Issue templates: the bug report asks for an `old.md` / `new.md` **or** `old.adoc` / `new.adoc` pair and the
  AsciiDoc plugin version.
- CONTRIBUTING.md: how to run the AsciiDoc tests, and that AsciiDoc fixtures follow the same rule.

### Release

- CHANGELOG `[Unreleased]`: Added (AsciiDoc support and its scope), Changed (viewer names "Rendered (side by side)" /
  "(merged)", **Compare Rendered Files...**).
- Release per [RELEASING.md](../../RELEASING.md), beta channel first (`1.5.0-beta`) to collect AsciiDoc feedback, then
  stable.
- PHASE4.md: status column filled in; open items moved to a "Not in phase 4" list or a later plan.

## Out of scope

New features.

## Done when

- The beta and the stable release are on Marketplace, and the listing says AsciiDoc diffs need the AsciiDoc plugin.
- SPECIFICATION.md describes the released product, and no doc still says AsciiDoc is out of scope.
