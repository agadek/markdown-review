Markdown Review

Review changes to Markdown files the way they look once rendered, right inside the diff window of IntelliJ IDEA and other JetBrains IDEs.

A text diff of Markdown shows syntax instead of content: a rewritten paragraph becomes a few red and green lines, a change in a table becomes shifted | characters, and re-indenting a list looks like everything changed. Markdown Review shows the same comparison the way the document looks once rendered, so the reviewer judges the content, not the markup. It does not open a window of its own: it adds viewers to the IDE's regular diff window, so it works wherever the IDE shows a diff of an .md file.

Install

  1. In the IDE, open Settings | Plugins | Marketplace.
  2. Search for Markdown Review and click Install.
  3. Open the diff of any Markdown file, for example from the Commit window (Ctrl+D). It opens in the rendered side-by-side viewer.

Requires IntelliJ IDEA (Community or Ultimate) or another IntelliJ-based IDE, version 2025.1 or newer, with JCEF (the default in JetBrains Runtime). Without JCEF the plugin stays out of the way and the diff window keeps the text viewer.

A build from GitHub installs with Settings | Plugins | ⚙ | Install Plugin from Disk...; such an install does not update itself.

Features

  • Rendered side-by-side diff Headings, paragraphs, list items, table rows and code blocks aligned in rows, with changed words highlighted inside changed blocks.
  • Merged view One column: removed parts red and struck through, added parts green. Handy for a large change.
  • Mermaid diagrams Drawn offline in the editor's theme. A changed diagram shows the old and new drawing, with a toggle for the line diff of its source.
  • Math $...$ and $$...$$ formulas drawn offline with KaTeX; a changed formula is highlighted as a whole.
  • Moved blocks Labeled at both ends with a link to the other end, instead of a deletion and an addition. Reverting moves the block back.
  • Per-block revert and apply Buttons on a changed block copy it to the other side, one Undo step each, on sides that can be edited.
  • Block source editing Double-click a block to edit its raw Markdown in place; Ctrl/Cmd+Enter saves, Esc cancels.
  • Block menu Right-click a block for Go to Source, Open in Text Diff Here (where pull request windows take review comments) and Show History for This Block.
  • Show Rendered Diff From the Git log, file history and the Commit window, even when diffs open with the text viewer by default.
  • Export Save the rendered diff as a standalone HTML file or a PDF to attach to a review or a ticket.
  • Custom stylesheet A CSS file of your own on top of the rendered view, for example to match your documentation site.
  • Text diff The IDE's built-in diff is always one click away in the viewer switcher.

The viewers work in the Commit window, file history, branch comparison and pull request windows. Compare any two files with Compare Markdown Files... from the project view's context menu or the Tools menu. F7 and Shift+F7 move between changes; Ctrl/Cmd+click on a block opens its source in the editor.

Supported Markdown

CommonMark with GitHub Flavored Markdown: tables, task lists, strikethrough, autolinks, footnotes and alerts. Also HTML blocks and inline HTML (sanitized), <details>, HTML comments, hard line breaks, thematic breaks, emoji shortcodes, wiki links ([[page]], [[page|label]]), YAML front matter, Mermaid diagrams and math. Relative images resolve against the file; remote images load only when enabled. The user interface is in English.

Settings

In Settings | Tools | Markdown Review:

Default viewer for Markdown diffsRendered side by side, rendered merged, or the IDE's text viewer. Switching the viewer in a diff window is remembered for that kind of window until this setting changes.
Ignore whitespace and line wrappingChanges that only re-wrap or re-indent text do not show as changes.
Collapse unchanged blocksLong runs of unchanged blocks fold away.
Pairing thresholdHow similar a removed and an added block must be to show as one modified block with a word diff. Lower pairs more rewrites, higher pairs fewer.
Load remote imagesOff by default: images from http(s) URLs are not loaded and nothing is fetched from the network.
Render Mermaid diagramsOff: diagrams are diffed line by line as code.
Render mathOff: formulas show as their TeX source.
Custom stylesheetA CSS file applied on top of the rendered view. It can set the --md-* theme variables and override any rule; the root element has the class mdr-theme-light or mdr-theme-dark.
Revert and apply buttonsShow them on changed blocks of sides that can be edited.
Large filesAbove a number of lines or a size, the rendered viewer shows a message with a button to open the text viewer instead.

The colors of added, removed and modified blocks and of changed words are set per color scheme in Settings | Editor | Color Scheme | Markdown Review; a color left unset follows the scheme's Diff colors.

Help

Open an issue with the bug report template. The most useful part is a small pair of Markdown files (old and new) that shows the problem. When the plugin throws an exception, the IDE's error dialog offers Report to Markdown Review on GitHub, which opens a prefilled issue; nothing is sent until you submit it.
