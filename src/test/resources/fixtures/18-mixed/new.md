# Markdown Review

An IntelliJ plugin for reviewing changes in Markdown files in rendered form.

## Features

- Side-by-side view
- Unified view with strikethrough
- Per-block revert

> Text mode uses the IDE's built-in diff.

## Installation

Install from Marketplace.

```bash
./gradlew buildPlugin
./gradlew runIde
```

| Shortcut | Action |
|---|---|
| F7 | Next change |
