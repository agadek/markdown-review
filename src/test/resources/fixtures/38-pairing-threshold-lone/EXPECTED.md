# 38-pairing-threshold-lone

One paragraph rewritten between two unchanged headings, the only paragraph on each side. A lone block pairs at half
the threshold, since a single rewritten paragraph is most likely the same paragraph. Similarity of the content words
(function words such as "the" are left out): 0.20, from the shared word "plugin".

- Threshold 0.3 (lone: 0.15): modified, with a word diff.
- Threshold 0.7 (lone: 0.35): `Install the plugin ...` removed, `Download the plugin as a ZIP file ...` added.
